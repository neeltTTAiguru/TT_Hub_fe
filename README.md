# feCRM (Frontend)

React + Vite frontend using Ant Design and React Router.

## Prerequisites
- Node.js 18+ recommended
- npm (comes with Node)

## Setup
```bash
cd /Users/joecindergrid/Desktop/crm/feCRM
npm install
```

## Run (dev)
```bash
npm run dev
```

The app will be available at `http://localhost:5173`.

## Notes
- Theme tokens are in `/Users/joecindergrid/Desktop/crm/feCRM/src/theme.ts`.
- Light/dark palette and Ant Design overrides live in `/Users/joecindergrid/Desktop/crm/feCRM/src/styles/theme.css`.
- Routes are defined in `/Users/joecindergrid/Desktop/crm/feCRM/src/App.tsx`.
